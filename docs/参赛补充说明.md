## 合规声明：本项目补充说明

- MCP 工具：12 个只读工具，加 2 个受控写工具（领券 `auto-bind-coupons`、下单 `create-order`），不支付、不买卡、不取消订单，见 [MCP_INTEGRATION.md](../MCP_INTEGRATION.md)。另有 2 个团餐专用只读工具（`query-promotions`、`query-meal-assistance`）。团餐已在模拟服务上验证、真实只读待用户验证，团餐真实下单未开放（官方端点上被代码拒绝）。
- 受控写工具需通过四道门：`--execute`、与记录匹配且未过期的摘要编号、固定写目标（本机回环或官方端点）、以及官方端点专有的真实写开关 + 终端亲手确认 + 金额与次数上限。**真实领券/下单默认关闭、未经真实验证。**
- 官方写通道代码已具备，但写调用只在本机回环模拟服务和网络桩上经自动测试验证；终端检查无法区分真人与被程序驱动的伪终端。
- 真实账户验证情况：v1 的真实只读有作者自述记录（2026-10-17/19，未经第三方复现，见 [真实验证与能力边界](真实验证与能力边界.md)）；v2 新增能力（多人、外送/得来速、团餐、券预览）与全部真实领券/下单均未用真实账户验证。
- 文档仅描述本项目自身能力，不含与其他品牌或产品的比较内容。
